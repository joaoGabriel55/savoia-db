# Settings

Open Settings with **⌘,** (Ctrl+,) or from the command palette.

- **General › Appearance.** *Match system*, *Light* or *Dark*. Match system follows the OS, including when it switches while Savoia is open. The palette commands *Theme: light*, *Theme: dark* and *Theme: match system* switch it too.
- **General › Updates.** Turns the update check at startup on or off. *Check now* checks right away.
- **General › Privacy.** *Offer to report crashes*. See [Privacy](privacy.md).
- **Dump tools.** The folder where your database client tools live.
- **Keyboard.** Every shortcut.
- **About.** The version, links, and the Ko-fi button.

Settings are saved in the app's data folder, next to your saved connections.
