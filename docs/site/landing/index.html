Your daily loop, without the weight.

Connect, query, fix a row, move on. These are screen recordings of the app at normal speed, on a local Postgres with the sample database from the repository.

Connect in one paste.

Paste a postgres:// or mysql:// URL and Import fills the form. Test tells you it works before you save.

Give production a red tag and it shows on every tab and in the status bar, so you always know where you are typing. SSH tunnels, TLS modes and read-only sessions are on the same form.

Connecting, in detail

Completion that reads your foreign keys.

Type JOIN and Savoia offers the whole clause, clubs c ON c.id = p.club_id, straight from the schema. Tables and columns complete as you type.

⌘ ↩ runs the statement under the caret. Big results stream in, and you can cancel at any time.

Writing and running SQL

Edit rows. See the SQL first.

Double-click a cell to change it. Nothing is sent yet: edits wait as pending changes, and Review SQL shows the exact statements.

Commit runs them in one transaction. If anything fails, it all rolls back and your changes stay pending.

Everything is in the free version, because there is only one.

  • ExploreA schema tree that loads as you open it, with counts, ER diagrams, table structure and DDL.
  • QueryConsole tabs, schema-aware completion, multiple result sets, sort, filter, copy as CSV, JSON or INSERT, and a searchable history.
  • Data viewBrowse and filter tables without SQL, add columns through foreign keys, summarize, and edit with a SQL preview.
  • Dump and importUses your pg_dump, psql, mysqldump or mysql, or a built-in engine. SQL scripts and CSV.
  • ConnectionsTLS modes, SSH tunnels with known_hosts checks, read-only sessions and color tags.
  • KeyboardA command palette (⌘⇧P) with every command and its shortcut. Light and dark themes that can follow your OS.
